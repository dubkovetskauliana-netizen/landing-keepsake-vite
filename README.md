# Keepsake — Адаптивний лендінг дизайн-агенції (Лабораторна робота №9)

Проєкт створено на сучасному стеку розробки: **Vite**, **Pug**, **SCSS (модульна архітектура + БЕМ)**, **PostCSS (Autoprefixer)**, **Sharp**, **Stylelint**, **Prettier** та **Husky + lint-staged**.

## Скрипти проєкту

- `npm run dev` — запуск локального сервера розробки Vite
- `npm run build` — продакшн-збірка проєкту в папку `dist/`
- `npm run preview` — локальний перегляд продакшн-збірки
- `npm run images` — автоматична конвертація зображень у AVIF, WebP та JPEG (`400w`, `800w`)
- `npm run lint` — перевірка стилів (Stylelint) та форматування коду (Prettier)
- `npm run format` — автоматичне форматування коду через Prettier
